# 我が家の黄金比 - プロダクト仕様書 v2.5

## 1. アプリ概要

**アプリ名**: 我が家の黄金比（Kitchen Research Notebook）

**コンセプト**: 
家庭料理のレシピを「研究ノート」として管理し、改良の履歴を記録・共有できるアプリ。料理を「再現可能な資産」として蓄積し、家族のレシピを次世代に継承する。

**ターゲットユーザー**:
- 細部にこだわる料理好き
- 家族のレシピを記録・継承したい人
- 効率的に家庭料理を管理したい人

**差別化ポイント**:
1. **バージョン管理（系統樹設計）**: レシピの改良履歴を親バージョンからの派生として記録
2. **黄金比ビジュアライザー**: 材料の分量を比率バーで可視化し、バランスを直感的に把握
3. **進化のタイムライン**: レシピがどのように改善されたかを縦型のタイムラインで閲覧
4. **黄金比スケーラー**: 味のバランス（比率）を保ったまま、人数に合わせて分量を自動計算

## 2. コア機能（実装済み）

### 2.1 レシピ管理 & エディタ
- レシピの作成・編集・削除
- セクション（材料グループ）管理
- 時系列の調理工程管理（ドラッグ＆ドロップ対応の下地あり）
- 工程と材料セクションの紐付け機能

### 2.2 進化するバージョン管理
- **系統作成**: 既存バージョンをベースにした新規バージョンの作成
- **縦型タイムライン**: 作成日、変更メモ、比較対象を一覧できる進化の記録
- **スマートナンバリング**: 修正（1.1）と大幅変更（2.0）を選択可能。ベースバージョンに応じた自動採番。

### 2.3 黄金比スケーラー
- 1人分〜N人分まで、1タップで全材料の分量を再計算
- 比率バーによる視覚的なバランス確認

### 2.4 プロフェッショナル調理ガイド
- **工程フォーカス**: 現在の工程をタップで強調表示。濡れた手でも自分の位置を見失わない設計。
- **コネクテッド材料**: 各工程で使用する材料グループをチップ形式で表示。

### 2.5 進化の比較（Delta View）
- 親バージョンと新バージョンの「増減」をバッジと矢印で可視化
- 分量の変化率（%）を自動算出

## 3. データモデル

### 3.1 エンティティ構成

```
Recipe (レシピ)
  └─ Version (バージョン) ← parent_version_id により系統を管理
       ├─ Section (セクション) ← 材料のグループ
       │    └─ Ingredient (材料)
       └─ Step (工程) ← 時系列順
            └─ StepSection (工程で使用するセクションの関連)
```

### 3.2 詳細定義（抜粋）

#### Version（バージョン）
```typescript
interface Version {
  id: string;                    // UUID
  recipeId: string;              // 親レシピのID
  parentVersionId?: string;      // 派生元バージョンのID（比較の基準）
  versionNumber: string;         // バージョン番号（例: 1.0, 1.1, 2.0）
  notes?: string;                // バージョンのメモ
  createdAt: string;             // 作成日時
  sections: Section[];
  steps: Step[];
}
```

### 3.3 データベーススキーマ（v3）

```sql
-- バージョンテーブル (Updated for v3)
CREATE TABLE versions (
  id TEXT PRIMARY KEY,
  recipe_id TEXT NOT NULL,
  parent_version_id TEXT,        -- 派生元を追跡
  version_number TEXT NOT NULL,
  notes TEXT,
  created_at TEXT NOT NULL,
  FOREIGN KEY (recipe_id) REFERENCES recipes(id) ON DELETE CASCADE,
  FOREIGN KEY (parent_version_id) REFERENCES versions(id) ON DELETE SET NULL
);
```

## 4. UI/UX 設計

### 4.1 デザインシステム「Golden Ratio」
- **カラーパレット**: 
  - メイン: 真鍮ゴールド（#B8860B）- 信頼と品質
  - アクセント: ディープチャコール（#4E342E）- 落ち着いた高級感
  - ベース: オフホワイト（#FAFAFA）- 清潔感と視認性
- **タイポグラフィ**: セクションタイトルは大文字＋字間調整でプロ仕様のノート感を演出

### 4.2 キッチン最適化設計
- **比率バー**: 材料の分量を最大値を100%としたバーで表示し、配合比を一目で理解可能。
- **ステップハイライト**: 料理中にタップしやすいよう、工程全体を大きなカードとして配置。選択中はゴールドの枠線で強調。
